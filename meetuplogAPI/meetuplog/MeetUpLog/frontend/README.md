# MeetupLog

그룹 채팅 기반 NLP 영화 추천 서비스

## 프로젝트 소개

MeetupLog는 사용자가 자체 웹 서비스에서 그룹 채팅방을 생성하고,
초대 링크를 외부 메신저에 공유하여 구성원을 모은 뒤,
채팅에서 나타난 영화 취향과 제약 조건을 NLP로 분석하여
그룹에게 적합한 영화를 추천하는 서비스입니다.
